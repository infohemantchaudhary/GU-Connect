# CampusOps AI

CampusOps AI is an AI-powered campus operations platform that transforms student complaints into actionable workflows.

## Problem
Students often struggle to report campus issues, identify the responsible department, and track whether their complaints are resolved.

## Solution
CampusOps AI allows students to report issues in natural language. The system identifies the problem, detects duplicate complaints, assigns the appropriate department, creates tickets, monitors resolution deadlines, and escalates overdue issues.

## Initial MVP Features
- Student complaint submission
- AI-based complaint classification
- Duplicate incident detection
- Department routing
- Ticket tracking
- Staff assignment
- SLA reminders and escalation
- Admin dashboard

## Initial Scope
The first version will focus on maintenance complaints such as broken ACs, classroom equipment, and Wi-Fi issues.

## Tech Stack
Next.js, TypeScript, Node.js, Express, PostgreSQL, and an LLM API.
